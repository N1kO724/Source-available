# Scene to Art Lab

Transform photographs into original art-directed posters using
source-specific composition, color, material, typography, negative
space, and natural edge dissolution.

## Features

- Source-specific visual analysis
- Watercolor, screenprint, ink-wash, relief print and expressive painting
- Poster-system selection
- Natural lost-edge treatment
- Source-derived color palettes
- Condensed editorial typography
- Vertical and landscape poster workflows
- Built-in image generation workflow

## Installation

In Codex, use the Skill installer with this directory:

https://github.com/N1kO724/Source-available/tree/main/scene-to-art-lab

Restart Codex after installation.

You can also copy the `scene-to-art-lab` folder into your personal
or project Skills directory.
